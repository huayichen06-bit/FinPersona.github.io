FinPersona UI iteration (2026-11-12)

Deploy:
- Upload the CONTENTS of this folder to the GitHub Pages repository root.
- Keep the assets folder at the same level as the HTML pages.

Files changed:
- index.html: appended the Before You Begin assessment section.
- get-started.html: added the final career-preference question, result comparison, development advice and PDF export.
- career-overview.html: career cards now render eight-dimension illustrative role profiles.
- how-it-works.html and about.html: navigation order unified.
- assets/style.css: styles for new sections, radar cards, report and responsive layouts.
- assets/career-data.js: shared dimensions, career descriptions and existing career weights.

Data:
- The 24 Likert answers remain in get-started.html and still determine the eight personal dimension scores.
- The selected career is stored in the selectedCareer variable in the assessment page and shown in the result page. It does not alter the Top 3 calculation.
- Career descriptions, dimensions and current weighting values are centralized in assets/career-data.js.
- Career radar charts are illustrative profiles generated by normalizing each role's existing dimension weights against that role's largest weight. They are not validated industry competency benchmarks.

Charts and PDF:
- Radar charts use native inline SVG generated by JavaScript (no chart library dependency).
- PDF export uses html2pdf.js (which uses html2canvas and jsPDF). The SVG charts are inline SVG elements; html2canvas rasterizes them as part of the report capture, so there are no separate Chart.js canvas elements to copy.

Scoring note:
- Three of the current role weight vectors sum to 1.05 (Risk Management, Compliance & Regulatory, Actuarial & Underwriting), while the others sum to 1.00. The displayed match score now divides by the sum of that role's weights so all scores stay within 0-100. The relative weights themselves are unchanged.
